ŞEVVAL GÜVEN — ANTI DİJİTAL KARTVİZİT

QR okutulduğunda telefonda açılan mobil uyumlu dijital kartvizit. Fotoğraf, iletişim bağlantıları, WhatsApp ve rehbere kaydetme özelliği içerir.

GitHub Pages kurulumu:
1. GitHub’da Sevval-Guven adlı repository oluşturun.
2. Bu klasördeki tüm dosyaları repository ana dizinine yükleyin: index.html, sevval-guven.jpg, anti-logo.png, sevval-guven.vcf, qr-kartvizit.png.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save seçin.
4. Site adresi: https://anticard.github.io/Sevval-Guven/

QR kod bu adrese yönlenir. Repository adı veya GitHub kullanıcı adı değişirse QR kodu da yeniden oluşturulmalıdır. Site yayınlanana kadar QR kod gerçek bir sayfa açmayabilir.
